# Сайт «Сочный вертел»

Публичный адрес: **https://sochnyvertelanapa.github.io/**

Одностраничный сайт без сборки: `index.html` + `styles.css` + `app.js`.

Оформление повторяет фирменный стиль сети с [sochnyvertel.ru](https://sochnyvertel.ru/):
тёмный фон с «углями», красно-оранжевый градиент `#ff2c2c → #ff5e2c`, заголовки шрифтом ROBO,
текст — Gilroy, логотип из франшизного сайта (`assets/logo.svg`). Шрифты лежат в `assets/fonts/`
и взяты с сайта сети — они лицензированы франчайзером; если сеть попросит, замените на
Google-шрифты (Manrope/Unbounded), поменяв `@font-face` в начале `styles.css`.
Все тексты и цифры, которые нужно менять, лежат в двух местах:

| Что менять | Где |
|---|---|
| Телефон, WhatsApp, соцсети, адрес, часы, тексты про доставку, порог барабана | `config.js` |
| Меню (категория, название, цена, описание, метка) | `data/menu.json` **или** лист «Меню» в Google Таблице |
| Акции (иконка, название, кратко, подробно, бейдж) | `data/promos.json` **или** лист «Акции» |
| Призы в барабане (что, сколько шариков) | `data/prizes.json` |
| Кто что выиграл | `data/winners.json` **или** лист «Победители» |
| Отметки «Я приду» | лист «Гости» (через Apps Script) или сообщения в WhatsApp |

## Как опубликовать изменения

```bash
scripts/deploy_site.sh "что поменяли"
```

Скрипт кладёт содержимое `site/` в публичный репозиторий
`sochnyvertelanapa/sochnyvertelanapa.github.io` и включает GitHub Pages.
Сайт обновляется через 1–2 минуты.

## Формат `data/winners.json`

```json
[
  { "date": "6 сентября", "name": "Анна К.", "prize": "Сертификат 5 000 ₽", "jackpot": "да" },
  { "date": "6 сентября", "name": "Игорь",   "prize": "Соус в подарок" }
]
```

Новые записи добавляйте **в начало** списка. Поле `jackpot` можно не указывать —
сертификаты и «шаурма каждый день» подсвечиваются золотым автоматически.

## Google Таблица (уже подключена)

Админка сайта: https://docs.google.com/spreadsheets/d/1fjJYKasAAQEN_V58Eb-zuodP6QFVPyaiiwf9N-IY0DY
(Google Drive → «Сочный вертел / Сайт»). Листы **Меню**, **Акции**, **Победители** сайт читает
напрямую — правки видны после обновления страницы (около минуты). Лист **Гости** заполняется
через Apps Script (ниже). Не переименовывайте листы и заголовки первой строки.

Создана скриптом `scripts/site_setup_google_sheet.py` (заголовки: `Категория | Название | Цена | Описание | Метка`,
`Иконка | Название | Кратко | Подробно | Бейдж | Ссылка`, `Дата | Имя | Приз | Джекпот`), доступ —
«все, у кого есть ссылка — читатель». ID таблицы прописан в `config.js → sheetId`.
Если таблица недоступна, сайт показывает данные из `data/*.json`.

## Отметки «Я приду»

- **Без настройки:** гость заполняет форму → открывается WhatsApp с готовым сообщением на номер из `config.js`.
- **С Apps Script (рекомендуется):** отметки сохраняются в лист «Гости», на сайте появляется счётчик
  «сегодня к нам собираются N гостей», а победители читаются из той же таблицы.
  Инструкция — в начале файла `apps-script/Code.gs` (5 минут). Полученный URL → `config.js` → `rsvpUrl`.
  Опционально: уведомления в Telegram о каждой отметке (свойства скрипта `TG_TOKEN`, `TG_CHAT`).

## Что нужно проверить перед запуском рекламы

- [ ] **Телефон** в `config.js` — взят из открытых справочников (+7 909 924-10-44). Убедитесь, что это ваш номер для заказов.
- [ ] **Часы работы** — на Чиббис указано 08:00–23:00, в других источниках 10:00–22:00.
- [ ] **Цены в меню** — из внутренних документов по акциям (Классическая 369, Остряк 379, Джигит 389, морс 90, соус 40, чеддер 60, фри мини 80).
      Меню на сайте — из фирменных макетов (шаурма курица/говядина, мини 220 ₽, закуски, соусы, добавки).
- [ ] **Сравнение цен** «по телефону vs в приложении» (`config.js → delivery.compare`) — подставьте реальную цену из Яндекс Еды или поставьте `null`, чтобы скрыть карточку.
- [ ] **Условия доставки** (200 ₽ / бесплатно от 1 500 ₽) — из рабочего чата, подтвердите.
- [ ] Ссылки на Instagram / Telegram / VK / Яндекс Еду.
- [ ] Точка на карте: координаты дома 182 по Крымской; при необходимости уточните `lat`/`lon`.
